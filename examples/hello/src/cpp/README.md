# Native sources for hello

This directory is built by the NDK (CMake + Ninja) when you run ring2apk build.

## Files

- main.c -- Android entry point. Defines android_main, creates a Ring VM
  state, and runs the embedded bytecode via ringappcode_run().
- CMakeLists.txt -- NDK build script. Builds the Ring VM (ring/) as a static
  library, links it with main.c and the generated bytecode to produce libmain.so.
- ring/ -- Ring VM source code (src/*.c + include/*.h), copied from your
  Ring installation at init time.

Generated at build time (not committed):
- build/gen/ringappcode.c / ringappcode.h -- Generated from ring/main.ring.
  Contains the hex-embedded Ring bytecode. Regenerated on every build.

## Customizing

- Edit ../ring/main.ring to change your Ring app logic.
- The library name must match android.app.lib_name in the manifest (default: main).
