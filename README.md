# Ring2APK

Build Android APKs from [Ring](https://ring-lang.github.io) applications without Gradle.

## Features

- **No Gradle** — calls SDK tools directly. Fast, debuggable, no daemon.
- **Transparent builds** — `--verbose` prints every shell command.
- **Native-first** — `android.app.NativeActivity` host, your `src/cpp` built with the NDK via `CMake` + `Ninja`.
- **Ring bytecode embedding** — compiles `ring/*.ring` to C bytecode (`ring -go -norun`) and links it into `libmain.so`. No `.ring` assets shipped in this mode.
- **Optional Java** — any `src/java/**/*.java` is compiled with `javac` and dexed with `d8` into `classes.dex`.
- **Ring-native config** — single `ring2apk.ring` hash list, defaults for every key, unknown keys preserved.
- **Multi-ABI** — `arm64-v8a`, `armeabi-v7a`, `x86`, `x86_64` (override per-build with `--target`).
- **Incremental** — skips when the APK exists and sources haven't changed (Murmur3 hash of Ring, Java, C/C++, assets, resources); `--rebuild` / `--force` forces a full rebuild.
- **Signing built in** — debug keystore auto-created at `~/.android/debug.keystore`; release signing from config or CLI, verified with `apksigner verify`. Passwords passed via temp files (`file:`), never `ps`-visible.
- **16 KB page-size ready** — native libs linked with `-Wl,-z,max-page-size=16384` (Android 15+ / Play Console).

## Requirements

**Ring 1.27+** — the `RING` environment variable pointing to your Ring installation is **strictly required**. Falls back to `ring` on `PATH`.

- **Android SDK** — `build-tools`, at least one `platforms;android-*` (default config uses 34, override in `ring2apk.ring`), `platform-tools` (`ANDROID_SDK_ROOT` / `ANDROID_HOME`)
- **Android NDK** (`ANDROID_NDK_ROOT` / `NDK_HOME` or `<sdk>/ndk/*`, latest picked)
- **JDK** (`JAVA_HOME` for `javac`/`keytool`, `d8` needs `android.jar`)
- **CMake + Ninja** (SDK `cmake` package or system `cmake`)
- **zip** — Linux/macOS on `PATH`

## Installation

Via RingPM:

```shell
ringpm install ring2apk from ysdragon
```

Uninstall:

```shell
ringpm uninstall ring2apk from ysdragon
```

Pre-built binaries for Linux, macOS, Windows, and FreeBSD are also available on the [Releases](https://github.com/ysdragon/ring2apk/releases) page.

## Quick Start

```bash
ring2apk init hello
cd hello
cat ring/main.ring          # ? "Hello from Ring on Android!"
ring2apk build              # → build/hello-debug.apk
ring2apk run                # build + install + launch + logcat
ring2apk build --release    # → build/hello-release.apk (needs keystore)
```

## How it works

1. `ring/main.ring` (and every transitive `load`) is compiled with `ring -go -norun` into `build/gen/ringappcode.c`/`ringappcode.h` (hex-embedded bytecode).
2. `src/cpp` (Ring VM + `main.c`) is built per-ABI with the NDK toolchain into `libmain.so`, linking in the generated bytecode.
3. Resources (`res/`), assets, native libs, and `classes.dex` are linked into an APK with `aapt2`/`zip`/`zipalign`/`apksigner`.

`?` output is piped to logcat (`RingOutput` tag) by `src/cpp/main.c`.

## Commands

Global flag: `--verbose` prints each shell command (accepted by every command).

### `init` — scaffold a project

```bash
ring2apk init <name>                  # default name: myapp
```

Creates:

```
hello/
  ring2apk.ring        # config (ringSrcDir = "ring")
  ring/main.ring       # ? "Hello from Ring on Android!"
  assets/              # empty, for raw assets
  res/values/strings.xml, colors.xml, styles.xml
  src/cpp/main.c       # android_main → Ring VM + ringappcode_run()
  src/cpp/CMakeLists.txt
  src/cpp/ring/src, include  # Ring VM vendored from $RING/language
  src/java/            # empty, for optional Java sources
  README.md, src/cpp/README.md
```

Fails if the directory exists. Fails if `RING` is unset or `$RING/language` missing.

### `build` — compile APK

```bash
ring2apk build
ring2apk build --release
ring2apk build --target=arm64-v8a
ring2apk build --target=arm64-v8a,armeabi-v7a
ring2apk build --rebuild        # alias: --force
ring2apk build --verbose
```

- Config is loaded and validated **before** the environment check — bad config is reported even without an SDK.
- `--target` overrides `Ring2ApkConfig[:targets]`.
- `--release` sets `debuggable=false`; signs with `:keystore` if set, else debug keystore.
- Skips when the APK exists and sources haven't changed (use `--rebuild` to force).
- Exit `1` on failure.

### `run` — build, install, launch

```bash
ring2apk run
ring2apk run --device=emulator-5554
ring2apk run --release --rebuild --no-logcat
```

- Checks environment, then `adb devices` (fails with "No device connected!" if none).
- Delegates to `build` (respects `--release`/`--rebuild`), then `adb install -r`, then `adb shell am start -n <package>/<activity>`.
- Activity resolved from `AndroidManifest.xml` (`MAIN` intent), fallback `<package>.MainActivity`.
- Follows `logcat --pid=<pid>` (or `grep <package>`) unless `--no-logcat`.

### `sign` — sign an APK

```bash
ring2apk sign
ring2apk sign --keystore=release.keystore --ks-pass=secret
ring2apk sign --keystore=ks --ks-pass=pw --key-alias=release --key-pass=kp
ring2apk sign path/to/app.apk
ring2apk sign --apk=path/to/app.apk
```

Resolution order:

1. CLI flags (`--keystore`, `--ks-pass`, `--key-alias`, `--key-pass`, `--apk`/positional).
2. `ring2apk.ring` (`:keystore`, `:keystorePassword`, `:keyAlias`, `:keyPassword`, `<outputDir>/<name>-<release|debug>.apk`).
3. Prompt for `keystore` password if missing.

Fails with `apksigner not found!` if the SDK has no `apksigner`. Fails with `No keystore specified!` (and help text) if no keystore after merging. Verifies with `apksigner verify -v`.

### `clean` — remove artifacts

```bash
ring2apk clean         # rm -rf build/
ring2apk clean --all   # also rm *.apk, *.aab, local.properties in project root
```

Never errors if `build/` is absent (exits `0`).

### `create-keystore` — make a release keystore

```bash
ring2apk create-keystore --dname="CN=Name,O=Org,C=US"
ring2apk create-keystore --name=my.keystore --alias=release --validity=10000 --dname="CN=...,O=...,C=US"
```

Prompts for password (min 6 chars) and, if `--dname` is omitted, for `CN`/`O`/`C`. Fails if file exists. Uses `keytool` via `JAVA_HOME`, passwords passed with `-storepass:file`.

### `help` / `version`

```bash
ring2apk help        # --help, -h, no args
ring2apk version     # --version, -v
```

## Configuration

`ring2apk.ring` in the project root assigns the global `Ring2ApkConfig` hash list. Missing keys fall back to defaults; unknown keys are preserved; corrupt/missing assignment returns `NULL` and fails the build.

```ring
Ring2ApkConfig = [
    # App identity
    :name = "hello",
    :packageId = "com.example.hello",
    :versionCode = 1,
    :versionName = "1.0.0",

    # Android SDK versions
    :minSdk = 21,
    :targetSdk = 34,
    :compileSdk = 34,

    # Target ABIs
    :targets = ["arm64-v8a", "armeabi-v7a"],

    # Directories
    :assetsDir = "assets",
    :resDir = "res",
    :srcDir = "src",
    :outputDir = "build",

    # Ring entry point
    :entryPoint = "main.ring",
    :ringSrcDir = "ring",          # "" = ship .ring as assets; "ring" = embed bytecode

    # App display
    :label = "hello",
    :orientation = "unspecified",

    # Permissions (uncomment as needed)
    # :permissions = ["android.permission.INTERNET"],
    # :features = ["android.hardware.touchscreen"]
]
```

| Key | Default | Constraint |
|---|---|---|
| `:name` | `"myapp"` | non-empty; output `build/<name>-<debug\|release>.apk` |
| `:packageId` | `"com.example.myapp"` | `a.b` form, each segment `^[A-Za-z][A-Za-z0-9_]*$` |
| `:versionCode` | `1` | integer |
| `:versionName` | `"1.0.0"` | string |
| `:minSdk` | `21` | `≥ 21` |
| `:targetSdk` | `34` | `≥ :minSdk` |
| `:compileSdk` | `34` | platform `android-<compileSdk>` must exist |
| `:targets` | `["arm64-v8a","armeabi-v7a"]` | subset of `arm64-v8a, armeabi-v7a, x86, x86_64` |
| `:assetsDir` | `"assets"` | copied verbatim into APK |
| `:resDir` | `"res"` | compiled with `aapt2 compile` |
| `:srcDir` | `"src"` | parent of `java/` and `cpp/` |
| `:outputDir` | `"build"` | build staging + final APK |
| `:entryPoint` | `"main.ring"` | file inside `:ringSrcDir` (embed) or `:assetsDir` (asset) |
| `:ringSrcDir` | `""` | `""` disabled; `"ring"` enables `ring -go -norun` embedding |
| `:permissions` | `[]` | `<uses-permission>` lines in generated manifest |
| `:features` | `[]` | `<uses-feature required="false">` lines |
| `:label` | `"My App"` | `android:label` |
| `:icon` | `""` | reserved; launcher icon auto-detected as `ic_launcher*` in `:resDir` |
| `:theme` | `"@android:style/Theme.NoTitleBar.Fullscreen"` | `android:theme` |
| `:orientation` | `"unspecified"` | `android:screenOrientation` |
| `:hardwareAccelerated` | `true` | `android:hardwareAccelerated` |
| `:requireGLES` | `""` | when set (e.g. `"0x00030000"`) emits `<uses-feature glEsVersion>` |
| `:keystore` | `""` | release keystore path |
| `:keystorePassword` | `""` | `file:`-passed to `apksigner` |
| `:keyAlias` | `""` | `--ks-key-alias` |
| `:keyPassword` | `""` | `file:`-passed as `--key-pass` |
| `:debuggable` | `true` | forced `false` by `--release` |

## Project Structure

```
hello/
  ring2apk.ring          # ← edit this
  AndroidManifest.xml    # optional; overrides generated manifest
  ring/main.ring         # Ring entry point (when ringSrcDir="ring")
  assets/                # → APK assets/ (images, sounds, data)
  res/values/strings.xml # → aapt2
  src/java/              # optional Java sources → javac/d8
  src/cpp/
    main.c               # android_main, starts Ring VM
    CMakeLists.txt       # NDK build (ring static lib + libmain.so)
    ring/src, include    # vendored Ring VM
  build/                 # aapt2/d8/zipalign/apksigner output
    gen/
      ringappcode.c/.h   # generated from ring/*.ring (do not edit)
    hello-debug.apk
```

## Manifest generation

No `AndroidManifest.xml` in the project root → `ring2apk` generates one:

- **No `src/java/**/*.java`** → `android.app.NativeActivity`, `android:hasCode="false"`, `<meta-data android.app.lib_name>` (from `AndroidManifest.xml` or default `main` → `libmain.so`).
- **With Java** → `<packageId>.MainActivity`, `hasCode="true"`, no `lib_name` meta.
- Launcher icon injected only if `res/**/ic_launcher*` exists.
- `requireGLES` emitted only when set.
- A missing `package=` in a supplied manifest is injected from `:packageId`.

## Build Pipeline

Eight steps, fixed order:

| # | Step | Tool | Skipped when |
|---|---|---|---|
| 1 | Prepare dirs | `makeDir`/`rmrf` | — |
| 2 | Copy assets | `copyDir` | `assets/` absent |
| 3 | Compile resources | `aapt2 compile` | `res/` absent |
| 4 | Embed Ring bytecode | `ring -go -norun` → `ringappcode.c` | `ringSrcDir=""` or missing |
| 5 | Build native libs | `cmake` + `ninja` per ABI | `src/cpp/CMakeLists.txt` absent (warns) |
| 6 | Compile Java | `javac` → `d8` → `classes.dex` | no `src/java/**/*.java` |
| 7 | Create APK | `aapt2 link` + `zip` + `zipalign -f 4` | — |
| 8 | Sign APK | `apksigner sign` | — (debug keystore auto-created) |

Native libs are linked with 16 KB page flags; `CMakeCache.txt` is wiped when `Debug`↔`Release` switches.

## Native libraries

Bring your own `src/cpp/CMakeLists.txt` defining a `SHARED` target named to match `android.app.lib_name` (default `main`). Vendor the Ring VM (`ring/src`, `ring/include`) and any C library you need inside `src/cpp`. Without `CMakeLists.txt` the build warns and packages no `.so` — a `NativeActivity` app won't launch.

## Environment

Auto-detected, overridable:

| Variable | Checked first | Fallback |
|---|---|---|
| `ANDROID_SDK_ROOT` | `ANDROID_HOME` | `~/Android/Sdk`, `~/android-sdk`, `/opt/android-sdk`, `/usr/local/android-sdk`, `~/Library/Android/sdk` |
| `ANDROID_NDK_ROOT` | `NDK_HOME` | `<sdk>/ndk/*` (latest) |
| `JAVA_HOME` | — | `~/open-jdk`, `/usr/lib/jvm/java-17-openjdk`, `/usr/lib/jvm/java-21-openjdk`, `/usr/lib/jvm/default-java`, macOS Zulu |
| `RING` | — | `ring` on `PATH` |

Inside the SDK the newest `build-tools/*`, `cmake/*`, and `platform-tools` are picked automatically.
